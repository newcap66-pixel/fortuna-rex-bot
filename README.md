# 🎰 Slots Showcase Bot

Витринный Telegram-бот для демонстрации слотов с реферальными ссылками.

---

## Быстрый старт

### 1. Установить Python-зависимости
```bash
pip install aiogram python-dotenv
```

### 2. Создать файл `.env`
```bash
cp .env.example .env
```
Отредактируйте `.env`:
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — ваш Telegram ID (узнать: @userinfobot)

### 3. Заполнить slots.json
Отредактируйте `slots.json` — добавьте свои слоты с реальными реф-ссылками.

### 4. Запустить
```bash
python bot.py
```

## Структура папки

```
your-bot/
├── bot.py          ← код бота (не трогать)
├── slots.json      ← ваш контент (редактировать)
├── stats.json      ← статистика кликов (создаётся автоматически)
├── images/         ← картинки слотов (см. ниже)
├── .env            ← токен и admin ID (создать из .env.example)
└── .env.example    ← шаблон
```

### Про папку images/

Картинки в `slots.json` теперь хранятся **локально**, в папке `images/`. Это надёжнее внешних ссылок — они никогда не перестанут грузиться и не зависят от сторонних сайтов.

В `slots.json` поле `"image"` указывает на путь внутри папки бота, например:
```json
"image": "images/gates_of_olympus.jpg"
```

**Важно при переносе на хостинг (Railway/Render/VPS):** обязательно загружайте папку `images/` вместе с `bot.py` — без неё картинки показываться не будут.

**Как добавить новую картинку вручную:**
1. Положите файл (jpg/png) в папку `images/`
2. В `slots.json` укажите путь к нему в поле `"image"`, например `"images/novo_slot.jpg"`

**Альтернатива — через сам бот (без доступа к файлам):**
Команда `/setimage` (только для админов) позволяет обновить картинку прямо в Telegram — отправленное фото сохранится как `file_id` и тоже будет работать без внешних ссылок.

## Команды бота

### Для всех пользователей
| Команда | Действие |
|---------|----------|
| `/start` | Главное меню с категориями |

### Только для админов
| Команда | Действие |
|---------|----------|
| `/addslot` | Добавить слот через диалог |
| `/removeslot` | Удалить слот кнопкой |
| `/listslots` | Список всех слотов |
| `/stats` | Статистика кликов по слотам |

---

## Формат slots.json

```json
[
  {
    "id": "уникальный_id",
    "name": "Название слота",
    "category": "Категория",
    "image": "https://... или file_id из Telegram",
    "url": "https://казино.com/?ref=ВАШ_КОД",
    "description": "Описание (можно оставить пустым)"
  }
]
```

**Для image** два варианта:
- Публичный URL картинки
- `file_id` из Telegram (получить: отправьте фото боту, бот ответит file_id)

## Как заменить контент

1. Открыть `slots.json`
2. Добавить/удалить/изменить объекты
3. Сохранить — бот подхватит изменения автоматически (без перезапуска)
